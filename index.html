DeepSeek Harness Desktop

为什么选择 DSH-UI 桌面客户端

基于现代 Rust + 原生 Web 容器的高性能轻量桌面解决方案

极致小巧 · 8.7MB

相较于传统 Electron 动辄 150MB+ 的臃肿体积，基于 Pake 架构的二进制仅 8.7MB，内存开销减少 80% 以上。

智能后台管理 · 双击即用

内置 Rust 原生生命周期管理引擎，无需手动敲命令行。双击自动静默拉起后端并智能握手，退出自动释放。

全平台原生支持

支持 macOS (Apple Silicon & Intel)、Windows 10/11 以及主流 Linux，提供原生应用、托盘与拖拽交互体验。
